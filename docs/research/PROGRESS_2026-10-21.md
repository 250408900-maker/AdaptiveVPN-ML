## Objective
Develop an ML-assisted network routing decision system using
multiple observation windows and measured path performance.

## Limitations
- V4 model has not undergone strong independent validation
- ML confidence is not demonstrated real-world accuracy
- Route-selection evidence is not full per-probe tunnel proof
- Measurements were not collected in paired controlled
  DIRECT-versus-WireGuard sessions
- A switch recommendation is not proof of better routing
- Dataset and model artifacts may remain local/untracked

## Next experiment
On a network where VPN usage is permitted:
1. Verify tunnel connectivity and endpoint reachability
2. Measure DIRECT and WireGuard against equivalent targets
3. Preserve timestamps, failures, interface and path evidence
4. Repeat sessions and evaluate uncertainty
5. Compare static, rule-based and ML-assisted decisions
