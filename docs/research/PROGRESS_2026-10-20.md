# AdaptiveVPN-ML — Experimental Progress (20 October 2026)

## Controlled network experiments

- NORMAL: 0.44 ms average TCP connection time; 0% TCP failures.
- HIGH_LATENCY: 200.59 ms; 0% TCP failures.
- PACKET_LOSS: 72.87 ms; 6.67% TCP failures; 33.33% ICMP nonresponse.

## Model evaluation

- Historical repeated lab observations: V3 10/15, V4 15/15.
- Fresh three-scenario controlled lab check: V4 3/3.
- Additional latency experiments:
  - 150 ms: predicted NORMAL (confidence 0.467).
  - 250 ms: predicted HIGH_LATENCY (confidence 0.910).
  - 300 ms: predicted HIGH_LATENCY (confidence 0.897).
  - Jitter (~204 ms mean): predicted HIGH_LATENCY (confidence 0.747).

## Routing controller

- Sustained degradation requires three consecutive high-latency observations.
- Route comparison uses an initial weighted heuristic.
- Switching recommendations require a minimum estimated 15% improvement.
- No actual VPN switching has been implemented.
- 35 automated tests passed on 20 October 2026.

## Limitations

- Lab measurements are not real-world VPN measurements.
- Historical repeated observations informed V4 development.
- The four additional conditions were not consecutive live monitoring windows.
- The route-comparison weights and thresholds have not been independently validated.
- The current controller uses latency persistence; independent persistent packet-loss handling remains future work.
- Multi-protocol VPN integration, real path comparison, DPI investigation, desktop UI and independent validation remain outstanding.
